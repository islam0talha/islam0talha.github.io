# Islam Talha — Portfolio

My personal portfolio website built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and [Framer Motion](https://www.framer.com/motion/).

## 🚀 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Font:** Geist (Vercel)
- **Deployment:** GitHub Pages (via GitHub Actions)

## 🛠 Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## 📦 Deployment

Pushing to `master` automatically triggers the GitHub Action at `.github/workflows/deploy.yml`, which builds the site and deploys to GitHub Pages.

## 🎨 Design

- **Style:** Minimalist / Editorial — Dark Technical

  - Background: `#0f0f0f`
  - Foreground: `#e6e6e6`
  - Accent: `#2dd4bf`
